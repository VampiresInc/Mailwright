# Mailwright 0.2.13 - Attachment subject autofill

- Fill an empty mail subject with the first available attachment name, including ordinary drag-and-drop attachments.
- Use the item name supplied by the game in the client language.
- Preserve custom subjects and forwarding subjects; leave the subject alone while you are editing it.
- Retry when attachment details become available without sending the draft automatically.

Confirmed working in-game on Forever by Arametheus. Automated regression tests passed.

Packages: Retail 12.1.5, Classic Era 1.15.9, Mists Classic 5.5.4,
Burning Crusade Anniversary 2.5.6, and Forever 1.60.1.
