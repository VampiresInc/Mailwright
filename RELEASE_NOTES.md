# Mailwright 0.2.5 - Retail 12.1.5 compatibility

- Update Retail interface metadata to 12.1.5 (120105), tested in-game by Arametheus.
- Update compatibility documentation and the combined WoWInterface package.
- Retain the AddOns settings panel, optional attachment tabs, and Forever alt-name fix.

Packages are provided for Retail 12.1.5, Classic Era 1.15.9, Mists Classic 5.5.4,
Burning Crusade Anniversary 2.5.6, and Forever 1.60.1.
Other clients receive the same addon behavior with the synchronized 0.2.5 version.

Download the ZIP for your client and extract Mailwright into Interface/AddOns.
Disable Postal while using Mailwright.
