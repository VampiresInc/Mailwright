# Mailwright 0.2.1

- Stable packages for tested Retail 12.1.0, Classic Era 1.15.9, Mists Classic 5.5.4, and Burning Crusade Anniversary 2.5.6.
- Corrected Era and Anniversary interface versions.
- Ruleset menu labels and group headings now appear only in Forever. Other clients show Alts and All Alts.
- Contacts and mailbox operations tested in game by Arametheus, including saved-data persistence on the tested Classic clients.

## Choose your download

- Mailwright-0.2.1.zip: Retail.
- Mailwright-0.2.1-classic.zip: Classic Era.
- Mailwright-0.2.1-mists.zip: Mists Classic.
- Mailwright-0.2.1-bcc.zip: Burning Crusade Anniversary.

Extract Mailwright into Interface/AddOns. Disable Postal while using Mailwright.

Classic's different-realm filter does not yet recognize connected realm groups.
