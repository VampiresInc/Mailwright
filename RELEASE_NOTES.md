# Mailwright 0.2.0 release series

Retail 0.2.0 is the first stable release, following successful in-game testing.
Forever 0.2.0-beta.1 remains beta. Other Classic variants remain on alpha.7 pending in-game testing.
This promotion changes release labeling and packaging; mailbox behavior is unchanged.

## Downloads

- Stable 0.2.0: Retail only, Mailwright-0.2.0.zip.
- Separate beta 0.2.0-beta.1: Forever only, Mailwright-0.2.0-beta.1-forever.zip.
- Extract the Mailwright folder into Interface/AddOns. Disable Postal.
- Do not install GitHub's Source code archives.

## Forever saved-data limitation

Build 1.60.1.69913 may fail to reload saved data. Successful restart testing used a local workaround not included in public downloads. Export contacts and verify persistence after a full restart. Addon-manager updates may overwrite locally patched manifests; preserve your workaround before updating.
